# Internationalization

All apps ship in **English, Macedonian and Albanian**. The
dictionaries live in `@velnes/i18n` (`en.ts` is the source of truth;
`mk.ts`/`sq.ts` are typed `Record<TranslationKey, string>` so a
missing key is a compile error, and a test guards non-empty values
and matching interpolation placeholders).

- The UI language is a per-employee preference (`employees.lang`,
  `PATCH /auth/me`), applied on login and switchable from the shell
  header. The public booking surface (Phase 7) gets a per-widget
  language setting instead.
- **The consumer app** (2026-09-22) is trilingual too, under the flat
  `c.*` keys. Its language comes, in order of authority, from the
  signed-in account (`client_users.lang`, chosen at registration,
  editable under My Velnes, `PATCH /client/me`), then this browser's
  last choice (`localStorage` `velnes.client.lang`), then the browser's
  own language when it is one of ours; English otherwise. A pill in
  the header and in the footer switches it (and saves it on the
  account when signed in); `<html lang>` follows. One i18next instance
  lives in `apps/consumer/src/lib/i18n-core.ts` so label helpers
  outside React speak the same language; page roots subscribe with
  `useTranslation()` so a switch re-renders everything. A test guards
  that every `c.*` key the app mentions exists (`t()` accepts any
  string, so a typo would otherwise render as itself).
- **Salon-authored content never translates** — service names,
  product names, descriptions are the salon's own words.
- The audit log records in English as the system of record.
- Server-generated sentences (booking refusals etc.) currently reach
  the UI in English; Phase 5's calendar increment adds structured
  `code + params` alongside the message so clients render them
  localized (additive contract change, English stays the fallback).
- **Native review pending:** the MK and SQ dictionaries were written
  by the assistant and should be skimmed by native speakers before
  real salons onboard. One file per language, flat key list.
